# Verdigris

A movement-first 2D action platformer (Unity WebGL build), played on [Holiday Games](https://www.holiday-games.com).

This repository only contains the built web game (`index.html`, `Build/`, `TemplateData/`). The Unity source lives separately.

- Controls: A/D move, Space jump, Shift dash, E / right mouse hook, J / left mouse attack (in the air over orange pads: pogo), Ctrl slide/roll, M map, P pause, Backspace back.
- Deploy: static site on Vercel (Framework Preset: Other, no build step).
